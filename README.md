# uddalok-bhattacharya

Personal portfolio website for **Uddalok Bhattacharya** — Video Editor crafting digital stories and cinematic edits.

## Features
- **Interactive Reactive Avatar**: Hand-drawn vector avatar that naturally blinks, and dynamically reacts with simultaneous wink/smile on hover or touch.
- **Minimal Clean Aesthetic**: Dark and rich purple skeuomorphic toggle, tactile vintage rocker switch, and high-retention creator presentation.
- **Curated Work Showcase**: High-performance video showcase with instant hover previews and responsive 16:9 & 9:16 vertical modal playback.
- **Comprehensive Services**: Detailed video post-production services including YouTube Editing, Viral Reels & Shorts, Cinematic Edits, Commercial Ads, and Color Grading.
- **Live IST Clock**: Continuous real-time Indian Standard Time (Asia/Kolkata) resting status indicator.

## Project Structure
